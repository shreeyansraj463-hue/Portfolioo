04 HOW I THINK

Strip away
the noise.

A difficult physics problem, a stubborn JavaScript bug or a complicated visual effect usually gets the same treatment.

I break it down. Find the fundamentals. Understand what is actually happening. Then build back from there.

I don't particularly enjoy memorising solutions. I want the moment when the logic finally clicks.
